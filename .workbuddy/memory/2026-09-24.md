## 四、本轮踩的坑（都已修，记下来）

1. ★ **块注释里写含「星号 + 斜杠」的 cron 字面量 ⇒ 注释提前闭合 ⇒ 整个脚本语法错误**。
   本项目 `serve-backend-fastcron.mjs` 的注释里**专门警告过这一条**，我还是踩了。
   ⇒ 文档/脚本注释里一律不写字面量，改写成「每 20 秒一轮」这种描述。
2. **`/auth/login` 不是登录路径**，白名单里写的是 `/user/login`。
   打错路径的后果特别隐蔽：白名单不命中 ⇒ 被拦截器拒 ⇒ 返回 `{"code":401,"message":"未登录"}`，
   **看起来像「密码错了」**。⇒ 判据里已把这条写进注释。
3. **`amount=12.00` 字面量断言报假红**：`BigDecimal` 经 Jackson 序列化成 `12`。
   金额精度由 `DECIMAL(10,2)` 列保证，不是由 JSON 字面量保证。⇒ 改锚数值相等。
4. **订单域「归属」口径是 403 + 明确文案**（`OrderService#requireBuyer` 注释写明是越权防线），
   与「商品可见性 → 404」不同。我按 404 写断言报了假红 ⇒ 已改断言并登记该信息泄露面为**观察项**（不顺手改）。
